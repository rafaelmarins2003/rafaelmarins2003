## Research

```txt
Thesis focus:
Natural language → intermediate DSL → deterministic BPMN generation
```

I am exploring how LLMs can generate process models more reliably by using compact intermediate representations, syntactic validation, deterministic transpilation, and model adaptation.

The goal is not just “make the model output XML and pray,” because prayer is not a compiler strategy.
