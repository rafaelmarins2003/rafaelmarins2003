### ❯ Selected work

```
$ ls ./selected-work
```

**[semantic-compression-tcc](https://github.com/rafaelmarins2003/semantic-compression-tcc)** &nbsp;·&nbsp; `Python` `Rust`<br>
Undergraduate thesis. A three-layer pipeline that turns natural language into valid BPMN: a compact **BPMN-DSL** intermediate representation (roughly 90% fewer tokens than raw BPMN XML), an **SFT + GRPO** alignment stage with verifiable rewards (syntactic, semantic, topological, compactness), and a **deterministic Rust transpiler** that guarantees XSD-conformant output by construction.

**[multiagent-finance](https://github.com/rafaelmarins2003/multiagent-finance)** &nbsp;·&nbsp; `TeX`<br>
Research paper (with Rian Maia de Freitas) on **multi-agent LLM debate** for financial portfolio analysis: models argue, critique, and converge, with full cost accounting across providers. Aimed at an AI-in-finance venue.

**[bec_detection](https://github.com/rafaelmarins2003/bec_detection)** &nbsp;·&nbsp; `Python`<br>
LLM-based detection of **Business Email Compromise**, mapped to CyBOK knowledge areas: a full pipeline from ingestion to classification, with an academic write-up.

**[vectordb_massivo](https://github.com/rafaelmarins2003/vectordb_massivo)** &nbsp;·&nbsp; `Python`<br>
**Hybrid retrieval at corpus scale:** dense and sparse search over large document collections, the ingestion-and-ranking backbone production RAG actually needs.

### ❯ Research

```
thesis: natural language → intermediate DSL → deterministic BPMN
```

I am exploring how LLMs can generate process models more reliably using compact intermediate representations, syntactic validation, deterministic transpilation, and model adaptation. The goal is not "make the model output XML and pray," because prayer is not a compiler strategy.
